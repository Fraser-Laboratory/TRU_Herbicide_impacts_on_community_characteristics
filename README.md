# How do plant communities respond to herbicide and ash application? A case study on invasive plant dynamics in a semi-arid grassland.

This repository contains all code used to calculate statistics and generate plots for the titled scientific publication. All code was written using the R programming language by:

- Ghassen Chaieb

- Matthew Coghill

- Jay Prakash Singh

Additional manuscript authors include:

- Rachel Whitehouse

- Lauchlan Fraser

The [Master_Code_Publication.R](Master_Code_Publication.R) script will import the relevant data files and generate the statistical outputs and figures used in the manuscript. Additionally, a QGIS project file and required geopackage layers are included for the production of Figure 1 in the manuscript. QGIS software is required to view this map and can be downloaded from this link: <https://qgis.org/download/>
